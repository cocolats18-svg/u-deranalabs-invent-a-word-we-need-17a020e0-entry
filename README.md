Invent a Word We Need: coin one new English word and define it in a single clear line of at most 140 characters.

## The word

**callhearsal** (n.): the private rehearsal of a phone call, lines and all, performed before you dare to dial.

## Run it

```sh
node main.ts
```

The program writes the word and its definition to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), and refuses to write anything outside the 1–140 character gate.
